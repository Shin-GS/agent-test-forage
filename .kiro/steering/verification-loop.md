# 검증 루프 (Verification Loop)

## 목적

코드 변경 후 "작동하는 상태"를 보장하기 위한 검증 사이클.

## 검증 단계

1. **빌드** — 컴파일 통과
2. **타입 체크** — 타입 에러 없음
3. **린트** — 코드 품질 규칙 위반 없음
4. **테스트** — 관련 테스트 통과
5. **문서 동기화** — (선택) 코드 변경이 문서에 영향을 주는지 확인

## 루프 규칙

| 상황 | 행동 |
|------|------|
| 1회 실패 | 해당 에러만 수정 → 해당 단계만 재실행 |
| 같은 에러 2회 반복 | 접근 방식 변경 (다른 방법 시도) |
| 같은 에러 3회 반복 | 즉시 중단 + 사용자에게 보고 + 대안 제시 |
| 수정이 다른 단계를 깨뜨림 | 전체 검증 단계 처음부터 재실행 |
| 5분 이상 같은 에러에 갇힘 | 중단 + 보고 |

## 검증 완료 보고

```
✅ 검증 완료
- 빌드: 통과
- 타입 체크: 통과
- 린트: 통과
- 테스트: N/N 통과
```
