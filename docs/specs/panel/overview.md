# 사이드 패널

## 개요

우측에 위치하는 다목적 보조 영역. 채팅과 동시에 봐야 하는 가벼운 정보를 보여주는 보조 창.

## 패널 표시/숨김/리사이즈

### 우측 사이드 패널

| 항목 | 정책 |
|------|------|
| 기본 상태 | Desktop: 열림, Tablet: 닫힘 |
| 토글 | 헤더 버튼 또는 단축키로 열기/닫기 가능 |
| 리사이즈 | 좌측 경계선 드래그로 너비 조절 |
| 너비 범위 | 최소 240px ~ 최대 뷰포트 50% |
| 저장 | localStorage에 열림/닫힘 상태 + 너비 저장 |
| 자동 열림 | 닫힌 상태에서 "결과 보기" 등 패널 연동 액션 시 자동으로 열림 |

### 좌측 사이드바 (대화 목록)

| 항목 | 정책 |
|------|------|
| 기본 상태 | Desktop: 펼침 (260px), Tablet: 접힘 (60px) |
| 토글 | 접기/펼치기 가능 |
| 접힌 상태 | 60px, 하단 네비게이션 아이콘만 표시 |
| 리사이즈 | 우측 경계선 드래그로 너비 조절 (펼침 상태에서만) |
| 너비 범위 | 최소 200px ~ 최대 400px |
| 저장 | localStorage에 접힘/펼침 상태 + 너비 저장 |

## 패널에 적합한 것 (채팅 맥락에 종속된 가벼운 조회)

- 레시피 실행 결과 보기
- 레시피 간략 보기 (스텝 구성 확인)
- 히스토리 미리보기 (최근 실행 건)
- 레시피 목록 탐색

## 별도 페이지로 분리할 것 (독립적이고 무거운 작업)

- 레시피 상세 작성/편집 (full form)
- 전체 히스토리 목록 (검색, 필터)
- 스펙 관리
- 설정
- 대시보드

## 기본 화면

레시피 목록과 히스토리 최근 건이 하나의 뷰에 공존.
탭으로 필터: [전체] [즐겨찾기] [내 레시피] [공통]

### 레시피 목록 정렬 우선순위
1. 이 대화에서 최근 사용한 레시피
2. 즐겨찾기한 레시피
3. 내 개인 레시피
4. 공통 레시피

### 레시피 목록 항목 표시
- 레시피명 + [서비스] + ⭐(즐겨찾기) + [▶](바로 실행)
- 마지막 실행 결과 한 줄 (시각 + 성공/실패)

### 최근 실행 (하단)
- 3~5건 미리보기
- [전체 히스토리 →] 링크 (별도 페이지)

### 하단 고정 액션
- [+ 레시피 만들기] (별도 페이지로 이동)

### Empty State

| 조건 | 표시 |
|------|------|
| 레시피 0개 | "아직 레시피가 없어요. 관리자에게 요청하거나 직접 만들어보세요." + [레시피 만들기] |
| 최근 실행 0건 | 섹션 숨김 또는 "아직 실행한 레시피가 없어요." |
| 검색 결과 없음 | "'{검색어}'에 해당하는 레시피가 없어요." |
| 해당 서비스 레시피 0개 | "이 서비스(XX)에 등록된 레시피가 없어요." + [전체 레시피 보기] |

## 상세 뷰 (스택 네비게이션)

- 레시피 상세: 스텝 구성 보기
- 실행 결과 상세: 뷰 타입(읽기 전용) / 에디터 타입(수정 가능 form)
- 뒤로가기로 이전 뷰 복귀

## 동작 규칙

- 레시피 실행 완료 시: 히스토리 목록 refresh (최신 건 상단)
- 카드 UI [결과 보기] 클릭: 패널에서 해당 결과 상세로 전환
- 레시피 목록 항목 클릭: 레시피 상세 뷰로 진입
- 레시피 [▶] 버튼 클릭: 채팅에 "XX 레시피 실행하기" 자동 발화 + 참조 태그 설정 + AI가 실행 모드 선택 이어감
- 뒤로가기: 이전 뷰로 복귀
- 대화방 처리 중(🔄) 상태이면 [▶] 버튼 비활성화
