# 작업 히스토리

## 개요

레시피 실행 이력을 기록하고 조회하는 기능.

## 저장 정책

- 레시피 실행 건만 저장
- 대화방 삭제해도 히스토리는 독립적으로 유지

## 표시 정보

- 실행 시각
- 레시피명
- 생성된 데이터 요약
- 성공/실패 상태

## 패널 내 히스토리

사이드 패널 기본 화면에서 최근 실행 건을 표시.
항목 클릭 시 패널 내에서 실행 결과 상세 보기.
