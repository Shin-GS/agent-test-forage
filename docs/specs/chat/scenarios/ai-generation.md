# 시나리오: AI 필드 값 생성

## 트리거

레시피 실행 중 스텝의 특정 필드에 "AI 생성" 값 소스가 지정되어 있을 때.

## 전체 흐름

```
레시피 스텝 실행 중 → "AI 생성" 필드 발견
    │
    ▼
FE → BE: AI 생성 요청 (필드 정보 + 컨텍스트)
    │
    ▼
[fast] AI 호출: 필드 값 생성
    │
    ▼
BE → FE: 생성된 값 반환
    │
    ▼
FE: 해당 필드에 값 삽입 → API 호출 진행
```

---

## AI 입력

```json
{
  "system": "시스템 프롬프트",
  "context": {
    "api": "POST /api/v1/orders",
    "apiDescription": "주문 생성",
    "field": "memo",
    "fieldType": "string",
    "hint": "테스트용 메모를 자연스럽게",
    "currentContext": {
      "memberId": "M-001",
      "productId": "P-123",
      "quantity": 2
    }
  }
}
```

## AI 출력

```json
{
  "value": "테스트 주문입니다. 배송 메모 없음."
}
```

---

## UI 동작

| 영역 | 동작 |
|------|------|
| 채팅 | 변화 없음 (진행 상태 블록 계속 표시) |
| 액션 피커 | 없음 |
| 사이드 패널 | 변화 없음 |
| 대화방 상태 | 🔄 처리 중 유지 |

사용자에게 AI 생성 과정은 보이지 않음 (내부 처리).

---

## 프롬프트 전문

### 시스템 프롬프트

```
API 요청의 특정 필드에 적절한 테스트 값을 생성해주세요.
실제 서비스에서 사용될 수 있는 자연스러운 값을 만들어주세요.

## 정보
- API: {method} {path}
- API 설명: {apiDescription}
- 필드: {field} ({fieldType})
- AI 힌트: {hint 또는 "없음"}
- 현재 컨텍스트 (이전 스텝 결과): {currentContext}

## 원칙
- 값만 반환하세요. 설명이나 따옴표 불필요.
- 필드 타입에 맞는 값을 반환하세요 (string이면 문자열, number면 숫자).
- 힌트가 있으면 힌트를 참고하세요.
- 컨텍스트의 다른 값과 어울리는 자연스러운 값을 생성하세요.
```

### 유저 메시지

```
필드 "{field}"에 적절한 값을 생성해주세요.
```
