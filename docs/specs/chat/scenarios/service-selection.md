# 시나리오: 서비스 선택

## 트리거

사용자가 채팅에서 메시지를 전송했을 때, 대화방에 서비스가 미지정인 상태.

## 전체 흐름

```
사용자 발화 (서비스 미지정)
    │
    ▼
[fast] AI 호출: 서비스 유추
  - 입력: 발화 + 서비스 목록 (30개, 이름만)
    │
    ├─ 유추 가능 (후보 1~3개)
    │     → 채팅: "XX 서비스에서 진행할까요?"
    │     → 액션 피커: [서비스A] [서비스B] [취소]
    │     → 선택 시: 대화방 서비스 설정 + intent-classification으로 진입
    │
    └─ 유추 불가
          → 채팅: "어느 서비스에서 진행할까요?"
          → 액션 피커: 전체 서비스 목록 (search-select) + [취소]
```

---

## AI 입력

```json
{
  "system": "시스템 프롬프트",
  "context": {
    "services": ["사람인", "잡코리아", "쇼핑몰", "..."],
    "history": "최근 대화 이력"
  },
  "userMessage": "입사지원 해줘"
}
```

## AI 출력

```json
{
  "intent": "service_select",
  "suggestedServices": ["사람인", "잡코리아"],
  "message": "입사지원 관련 서비스가 여러 개 있어요. 어느 서비스에서 진행할까요?"
}
```

---

## UI 동작

### 유추 가능 (후보 1~3개)

| 영역 | 동작 |
|------|------|
| 채팅 | AI message 표시 |
| 액션 피커 | 서비스 버튼 목록 + [취소] |
| 사이드 패널 | 변화 없음 |
| 대화방 상태 | 🟡 입력 대기 |

사용자 액션:
- 서비스 선택 → 대화방 서비스 자동 설정 + 헤더 업데이트 + intent-classification 재실행
- [취소] → 채팅 input 복귀

### 유추 불가

| 영역 | 동작 |
|------|------|
| 채팅 | "어느 서비스에서 진행할까요?" |
| 액션 피커 | search-select (서비스 검색) + [취소] |
| 사이드 패널 | 변화 없음 |
