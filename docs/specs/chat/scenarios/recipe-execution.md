# 시나리오: 레시피 실행

## 트리거

- 의도 분류에서 [자동 실행] 또는 [직접 입력하며 실행] 선택 시
- 플랜에서 [자동 실행] 선택 시

## 전체 흐름

```
실행 시작
    │
    ▼
채팅: 진행 상태 블록 표시 (스크롤되는 메시지)
대화방 상태: 🔄 처리 중
입력: 차단 + [중지] 버튼 표시
    │
    ▼
스텝 순차 실행 (FE 브라우저에서 외부 API 직접 호출)
    │
    ├─ 스텝 완료 → 진행 상태 업데이트 (✅ + 결과 한 줄)
    │              BE에 스텝 결과 저장 API 호출
    │
    ├─ 사용자 입력 필요 (직접 입력 모드 or AI가 판단 불가)
    │     → 대화방 상태: 🟡 입력 대기
    │     → 액션 피커: 해당 변수 form (prefill 포함)
    │     → 입력 완료 후 → 다음 스텝 이어서 실행
    │
    ├─ 스텝 조건 미충족 → ⏭️ 스킵
    │
    ├─ 인증 에러 (401) → 카드 UI: [로그인하러 가기] [로그인 완료]
    │
    ├─ 권한 에러 (403) → 카드 UI: [다른 계정으로 로그인] [레시피 중단]
    │
    ├─ 실패 (500, 타임아웃 등) → ❌ + 카드 UI: [다시 실행]
    │
    └─ 전체 완료
          → 채팅: AI "실행이 완료되었습니다" + 결과 템플릿 메시지
          → 카드 UI: [결과 보기]
          → 사이드 패널: 히스토리 refresh
          → 대화방 상태: 유휴
```

## UI 동작

### 진행 상태 블록 (채팅에 스크롤 메시지로 표시)

```
📋 입사지원 실행 중

✅ 1. 로그인 확인 — 성공
✅ 2. 이력서 확인 — "프론트엔드 개발자 이력서" 발견
⏭️ 3. 회원가입 (스킵)
🔄 4. 공고 선택 (입력 대기 중)
⬜ 5. 입사지원 제출
```

### 입력 차단 영역

```
┌─────────────────────────────────────────────┐
│  레시피 실행 중...                    [중지]  │
└─────────────────────────────────────────────┘
```

### 사용자 입력 필요 시 액션 피커

```
┌──────────────────────────────────────┐
│ 공고를 선택해주세요             [✕]   │
│                                      │
│ 🔍 [네이버 백엔_________]            │
│   네이버 백엔드 개발자 (3년차)        │
│   네이버 백엔드 시니어 (7년차)        │
│                                      │
│           [취소]  [선택 완료]         │
└──────────────────────────────────────┘
```

- prefill된 값은 출처 뱃지 표시 (🗣️🔗📌)
- [취소] → 전체 레시피 중단

### 완료 시

```
📋 입사지원 완료 ✅

AI: 입사지원이 완료되었습니다.
    - 지원번호: APP-2026-0831
    - 공고: 네이버 백엔드 개발자

┌─────────────────────────────────────────┐
│ 📄 입사지원 결과                         │
│ 2026-08-27 14:30                        │
│                          [결과 보기]     │
└─────────────────────────────────────────┘
```

## 플랜 실행 모드

플랜(레시피 여러 개)인 경우:

```
📋 플랜 실행 중

✅ 1. 이력서 작성 — 이력서 ID: RES-001
🔄 2. 포지션 탐색
   ├ ✅ 로그인
   ├ 🔄 포지션 목록 조회
   └ ⬜ 결과 추출
⬜ 3. 입사지원
```

- 현재 실행 중인 레시피만 스텝 펼침
- 완료된 레시피는 접힘 (결과 한 줄)
- 레시피 간 데이터 전달: 이전 레시피 결과 정의(④) → 다음 레시피 입력으로 자동 매핑
- 실패 시: 전체 중단 + "레시피 N에서 실패. 이전 레시피는 이미 완료됨" 안내

---

## 중지

- [중지] 클릭 → 현재 스텝까지 완료 후 중단
- 진행 상태: ⏹️ 표시
- 카드 UI: [이어서 실행] (중단 지점부터 재개)
- 히스토리: "부분 완료" 상태로 저장

---

## 프롬프트

레시피 실행 자체에는 AI 호출 없음 (FE가 스텝 순서대로 API 호출).
AI가 관여하는 순간:
- "AI 생성" 값 소스 필드 → ai-generation.md 참조
- 실행 완료 후 결과 템플릿 미정의 시 → result-summary.md 참조
- prefill (대화 맥락에서 값 추출) → intent-classification에서 extractedValues로 이미 처리됨
