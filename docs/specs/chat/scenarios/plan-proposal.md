# 시나리오: 플랜 제안

## 트리거

AI가 [Tool Use 호출](intent-classification.md)에서 `propose_plan` tool을 선택한 경우
(여러 레시피를 순서대로 실행하는 복합 작업).

## 전체 흐름

```
Tool Use에서 propose_plan 호출 (recipeIds: [1, 3, 5])
    │
    ▼
BE: recipeIds로 레시피 상세 조회 (이름, 설명, 사용자 입력 변수)
    │
    ▼
채팅: FE 고정 템플릿 (레시피 이름 순서로 구성)
액션 피커: 플랜 제안 UI
    │
    ├─ 사용자: 수정 (스킵/순서변경/제거/추가/값 지정)
    │
    └─ [자동 실행] → recipe-execution (플랜 모드)
```

---

## AI 응답 (tool call)

```json
{
  "toolCalls": [
    {
      "function": {
        "name": "propose_plan",
        "arguments": {
          "recipeIds": [1, 3, 5],
          "extractedValues": { "positionId": "1" }
        }
      }
    }
  ]
}
```

- `propose_plan`은 **message를 생성하지 않는다.** 안내 문구는 FE가 `recipeIds`로 레시피 상세를 조회해 고정 템플릿으로 구성한다.
- 플랜 모드는 항상 `AUTO`로 고정 (MODE 선택 없음).

---

## UI 동작

| 영역 | 동작 |
|------|------|
| 채팅 | FE 고정 템플릿 (레시피 이름 순서) |
| 액션 피커 | 플랜 제안 UI (아래 참조) |
| 사이드 패널 | 변화 없음 |
| 대화방 상태 | 🟡 입력 대기 |

### 액션 피커: 플랜 제안

```
┌─────────────────────────────────────────────────────────┐
│ 📋 실행 계획                                       [✕]   │
│                                                         │
│ [≡] ☑ 1. 이력서 작성   [사람인]  [값 지정 ▾]  [🗑]       │
│ [≡] ☑ 2. 포지션 탐색   [사람인]  [값 지정 ▾]  [🗑]       │
│ [≡] ☑ 3. 입사지원      [사람인]  [값 지정 ▾]  [🗑]       │
│                                                         │
│ [+ 레시피 추가]                                           │
│                                                         │
│            [취소]  [자동 실행]                             │
└─────────────────────────────────────────────────────────┘
```

### 사용자 액션

| 동작 | UI | 결과 |
|------|------|------|
| 레시피 스킵 | 체크박스 해제 | 해당 레시피 실행 안 함 |
| 순서 변경 | [≡] 드래그 | 실행 순서 변경 |
| 레시피 제거 | [🗑] 클릭 | 플랜에서 완전 제거 |
| 레시피 추가 | [+ 레시피 추가] → 인라인 검색 | 플랜 하단에 추가 |
| 값 지정 | [값 지정 ▾] → 아코디언 펼침 | 해당 레시피의 입력 변수 미리 설정 |
| 자동 실행 | [자동 실행] 클릭 | recipe-execution 플랜 모드로 진입 |
| 취소 | [취소] 또는 [✕] | AI "취소되었습니다" → 채팅 input 복귀 |

### 값 지정 아코디언

```
│ [≡] ☑ 1. 이력서 작성   [사람인]  [값 지정 ▲]  [🗑]       │
│   ┌─────────────────────────────────────────────────┐   │
│   │ 이름 *    [홍길동]         🗣️ 발화                │   │
│   │ 경력     [___________]                          │   │
│   └─────────────────────────────────────────────────┘   │
```

값 출처 뱃지: 🗣️ 발화 / 🔗 이전 결과 / 📌 기본값 / ✏️ 직접 입력

### 레시피 추가 (인라인 검색)

```
┌─ 레시피 추가 ───────────────────────────────────────┐
│ 🔍 [이력서_______]                                  │
│  이력서 수정       [사람인]                           │
│  이력서 삭제       [사람인]                           │
└─────────────────────────────────────────────────────┘
```

- 현재 대화방 서비스 기준 우선 필터링
- 항목 클릭 → 플랜 목록 하단에 추가

---

## 프롬프트

플랜 제안 자체는 Tool Use 호출(`propose_plan`) 단계에서 이미 결정됨.
별도 AI 호출 없음 (BE가 `recipeIds` 배열로 레시피 상세를 조회하여 FE에 전달).
