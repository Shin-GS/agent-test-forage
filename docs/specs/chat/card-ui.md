# 카드 UI

## 개요

대화 영역에 삽입되는 시각적 블록. 사이드 패널의 상세 뷰를 여는 진입점 역할.

## 유형

| 유형 | 구성 | 동작 |
|------|------|------|
| **실행 모드형** | 레시피명 + 한줄 설명 + 필요한 값 목록 + [바로 실행] [값 확인 후 실행] | 무엇을·어떤 값으로 실행하는지 보여주고 모드 선택 (아래 상세) |
| **결과 제공형** | 레시피명 + 실행 시각 + [결과 보기] | 사이드 패널에 결과 상세 노출 (프로토타입: [결과 보기] 비활성/생략, 결과는 텍스트 메시지로 전달 — [execution.md 결과 표시 스코프](../recipe/execution.md#실행-완료--결과-요약)) |
| **재시도형** | 실패 안내 + [다시 시도] | 중단 스텝부터 재실행 |
| **인증 요구형** | [로그인하러 가기] + [로그인 완료] | 새 탭 → 복귀 후 재개 |
| **후보 선택형** | 유사 레시피 목록 + [없으면 다시 설명할게요] | 클릭 시 해당 레시피 실행 플로우 진입 |
| **참고 자료형** | 조회한 소스 링크 버튼 리스트 | 클릭 시 원본 새 탭으로 열기 |

## 실행 모드형 상세

레시피 매칭 후, "무엇을 실행하는지 + 어떤 값이 필요한지"를 보여주고 실행 모드를 고르게 한다. 버튼만 노출하지 않는다.

```
📋 입사지원 (사람인)
사람인 채용공고에 이력서를 제출합니다.

필요한 값:
🗣️ 회사명       "네이버"        (필수)
📌 직무          "백엔드"        (기본값)
✏️ 지원 메모     (입력 필요)      (필수)

[바로 실행] [값 확인 후 실행]
```

- **레시피명 + 한줄 설명**: 무엇을 실행하는지
- **필요한 값 목록**: 각 입력 변수의 라벨 / 현재값 / 값 출처 / 필수 여부
  - 값 채워짐 → 값 + 출처 아이콘 (🗣️ 발화 / 📌 기본값)
  - 미충족 필수값 → "(입력 필요)" (✏️ 미입력)
- **버튼 동작**: [바로 실행]=발화/기본값으로 즉시 진행, [값 확인 후 실행]=액션 피커로 전체 값 확인·수정 후 진행
- 카드 필드 구조: [messaging.md execution_mode 카드 상세](../common/messaging.md#execution_mode-카드-상세)
- 동작 정의: [recipe/execution.md 실행 모드](../recipe/execution.md#실행-모드)

## 후보 선택형 상세

AI 의도 매칭이 애매할 때(유사 레시피 여러 개):

```
AI: 요청하신 내용과 비슷한 레시피가 여러 개 있어요.

  1. 입사지원 (사람인)
     "사람인 채용공고에 이력서 제출"

  2. 입사지원 (잡코리아)
     "잡코리아 채용공고에 이력서 제출"

  3. 입사지원 (자체 ATS)
     "내부 채용시스템에 지원"

  [없으면 다시 설명할게요]
```

- 후보 5개 이상 시 상위 3개만 표시 + "더보기" → 사이드 패널 레시피 목록으로 유도

## 참고 자료형 상세

정보 조회(investigate) 후 AI가 답변할 때, 참조한 소스의 원본 링크를 답변 하단에 **버튼 리스트**로 표시. (출처 인용 UX)

```
AI: 회원가입 시 약관 동의는 필수이며, 만 14세 미만은 보호자 동의가 필요합니다.

참고한 자료:
[🎫 PROJ-1234 회원가입 정책]  [📋 POST /api/v1/users]
```

| 소스 | 버튼 표시 | 클릭 동작 |
|------|----------|----------|
| Jira | 🎫 티켓키 + 제목 | Jira 티켓 URL 새 탭 |
| API 스펙 | 📋 method + path | 스펙 상세 (사이드 패널 or 내부 뷰) |
| Figma (추후) | 🎨 프레임명 | Figma URL 새 탭 |

- 버튼은 답변 메시지 하단에 가로 배치 (개수 많으면 줄바꿈)
- 조회한 소스가 없으면 참고 자료 섹션 미표시
- 상세 흐름: [정보 조회 루프](scenarios/investigation.md)
