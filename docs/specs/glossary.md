# 용어 사전

| 용어 | 정의 |
|------|------|
| **레시피** | 작업의 실행 순서를 정의한 워크플로우. 순차 실행되는 스텝의 집합 |
| **스텝** | 레시피 내 개별 실행 단위. 타입: API / 스크립트 / 레시피 / 사용자 입력 |
| **서브레시피** | 레시피 스텝에서 호출하는 다른 레시피. 레시피를 조립하여 재사용 가능 |
| **액션 피커** | 채팅 input 영역에 겹쳐 노출되는 구조화된 입력 UI. 취소 버튼 상시 노출 |
| **사이드 패널** | 우측에 위치하는 다목적 보조 영역. 레시피 목록, 히스토리, 실행 결과 등 표시 |
| **카드 UI** | 대화 영역에 삽입되는 시각적 블록. 사이드 패널의 상세 뷰를 여는 진입점 |
| **작업 히스토리** | 레시피 실행 이력. 대화방 삭제와 독립적으로 유지 |
| **참조 태그** | 채팅 input 상단에 표시되는 패널 컨텍스트 표시. AI에게 레시피 ID 등을 함께 전달 |
| **스펙** | 외부 서버의 OpenAPI 스펙. 레시피에서 호출 가능한 API 목록의 원천 |
| **인증 프로필** | 외부 서버의 로그인 정보. name + loginPageUrl 쌍 |
| **공통 레시피** | 관리자가 생성. 모든 사용자에게 노출 |
| **개인 레시피** | 사용자 본인만 사용하는 레시피 |
| **실행 모드** | 레시피 실행 시 선택하는 모드. 자동 실행 / 직접 입력하며 실행 |
| **플랜** | AI가 레시피 여러 개를 조합한 1회성 실행 계획. 저장하지 않음 |
| **Body 생성 전략** | API 스텝의 요청 본문 생성 방식. FIXED / AI_GENERATE / AI_FILL |
| **Extract** | API 응답에서 JSONPath로 변수를 추출하는 정의 |
| **대상 서비스** | 레시피가 어느 사이트를 위한 것인지 나타내는 메타 정보 |
| **대화방 서비스** | 대화방에 설정된 대상 서비스. 해당 서비스의 레시피를 우선 매칭 |
| **뷰 타입** | 사이드 패널에서 읽기 전용으로 결과를 표시하는 형태 |
| **에디터 타입** | 사이드 패널에서 수정 가능한 동적 form으로 결과를 표시하는 형태 |
| **서비스 설명** | 스펙(서버)의 메타 정보. description/domain/capabilities/notes. AI 서비스 매칭 컨텍스트로 활용 |
| **정보 조회 (investigate)** | 정책/기능 질문에 답하기 위해 AI가 정보 소스를 반복 조회하는 agentic loop. 읽기 전용, 승인 불필요 |
| **커넥터** | investigate가 조회하는 정보 소스 추상화. api_spec / jira (프로토타입), figma (추후) |
| **참고 자료 카드** | 조회한 소스의 원본 링크를 버튼 리스트로 보여주는 카드 UI (출처 인용) |
