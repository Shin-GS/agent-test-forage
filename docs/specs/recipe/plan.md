# 플랜 (Plan)

## 개요

AI가 사용자 발화를 분석하여 기존 레시피 여러 개를 조합한 실행 계획. 1회성이며 저장하지 않음.

- **레시피** = 등록된 작업 (저장, 재사용)
- **플랜** = AI가 레시피 여러 개를 조합한 실행 계획 (1회성)

---

## 플로우

```
사용자 발화: "입사지원 해줘"
    │
    ▼
AI 분석: 이 작업에 필요한 레시피 조합 판단
    │
    ▼
플랜 제안 (액션 피커로 표시)
    │
    ├─ 사용자: 수정 (스킵/순서변경/값 지정)
    │
    └─ [자동 실행] 클릭
         │
         ▼
    플랜 실행 (레시피 순차 자동 실행)
         │
         ├─ 각 레시피 완료 시: 결과 저장 + 다음 레시피에 결과 전달
         ├─ 사용자 입력 필요 시: 액션 피커 (prefill 포함)
         ├─ 실패 시: 중단 + 안내
         │
         └─ 전체 완료: 결과 카드 UI
```

---

## 플랜 제안 (액션 피커)

```
┌─────────────────────────────────────────────────────────┐
│ 📋 실행 계획                                       [✕]   │
│                                                         │
│ ☑ 1. 이력서 작성      [사람인]   [값 지정 ▾]              │
│ ☑ 2. 포지션 탐색      [사람인]   [값 지정 ▾]              │
│ ☑ 3. 입사지원         [사람인]   [값 지정 ▾]              │
│                                                         │
│            [취소]  [자동 실행]                             │
└─────────────────────────────────────────────────────────┘
```

### 사용자가 할 수 있는 것

| 동작 | UI |
|------|------|
| 레시피 스킵 | 체크박스 해제 |
| 순서 변경 | 드래그 핸들 (≡) |
| 레시피 추가 | [+ 레시피 추가] 버튼 → 인라인 검색/선택 |
| 레시피 제거 | 행의 [🗑] 버튼 |
| 값 미리 지정 | [값 지정 ▾] 클릭 → 아코디언 펼침 |
| 전체 취소 | [✕] 또는 [취소] |

모든 수정은 액션 피커 내부 UI에서 완결 (채팅 입력은 차단 상태).

### 레시피 추가 (인라인 검색)

[+ 레시피 추가] 클릭 시 액션 피커 내부에 검색 UI 인라인 노출:

```
┌─ 레시피 추가 ───────────────────────────────────────┐
│ 🔍 [이력서_______]                                  │
│                                                     │
│  이력서 수정       [사람인]                           │
│  이력서 삭제       [사람인]                           │
│  이력서 조회       [잡코리아]                         │
└─────────────────────────────────────────────────────┘
```

- 타이핑하면 레시피명/태그로 실시간 필터링
- 결과 항목 클릭 → 플랜 목록 하단에 추가 + 검색 UI 닫힘
- 현재 대화방 서비스 기준으로 우선 필터링 (다른 서비스도 보이되 하단에)

### 값 지정 (아코디언)

[값 지정 ▾] 클릭 시 해당 레시피의 사용자 입력 변수가 인라인으로 펼쳐짐:

```
│ ☑ 1. 이력서 작성      [사람인]   [값 지정 ▲]              │
│   ┌─────────────────────────────────────────────────┐   │
│   │ 이름 *    [홍길동]         📌 기본값              │   │
│   │ 경력     [___________]                          │   │
│   └─────────────────────────────────────────────────┘   │
```

- 이미 채워진 값은 출처 뱃지 표시
- 수정 가능
- 다시 클릭하면 접힘

---

## 데이터 자동 채움 우선순위

| 우선순위 | 소스 | 뱃지 |
|---------|------|------|
| 1 | 이전 레시피 실행 결과 | 🔗 이전 결과 |
| 2 | 사용자 발화에서 AI가 추출 | 🗣️ 발화 |
| 3 | 레시피에 정의된 기본값 | 📌 기본값 |
| 4 | 채울 수 없음 → 액션 피커로 물어봄 | ✏️ 직접 입력 |

- 모든 값은 수정 가능 (자동 채움이어도 사용자가 바꿀 수 있음)
- 수정하면 뱃지가 ✏️로 변경

---

## 실행 중 진행 상태

```
📋 플랜 실행 중

✅ 1. 이력서 작성 — 이력서 ID: RES-001
🔄 2. 포지션 탐색
   ├ ✅ 로그인
   ├ 🔄 포지션 목록 조회
   └ ⬜ 결과 추출
⬜ 3. 입사지원
```

- 현재 실행 중인 레시피만 스텝 펼침 (접기/펼치기)
- 완료된 레시피는 접힘 (결과 한 줄만)
- 스킵된 레시피: ⏭️ 표시

---

## 실행 모드

플랜 시작 시 한번 승인 → 쭉 자동 진행. 중간에 사용자 입력 필요할 때만 액션 피커로 멈춤.

(레시피 단위 승인 없음 — 플랜의 목적이 "묶어서 한번에"이므로)

---

## 실패 처리

- 실패 시: 전체 중단
- 안내: "레시피 N에서 실패했습니다. 레시피 1~(N-1)은 이미 완료되었습니다."
- 이미 실행된 레시피의 결과는 되돌릴 수 없음 (외부 서버에 데이터 생성됨)
- 카드 UI: [다시 실행] (실패한 레시피부터 재개)

---

## 스킵 시 데이터 전달

레시피 A를 스킵했는데 레시피 B가 A의 결과를 필요로 하는 경우:
- AI가 대화 이력에서 관련 값 탐색 → 있으면 prefill
- 없으면 액션 피커로 사용자에게 물어봄

---

## 저장 정책

- 플랜 자체는 저장하지 않음 (1회성)
- 플랜 내 각 레시피의 실행 결과는 정상적으로 히스토리에 저장됨

## 내부 구현 통일

모든 레시피 실행은 내부적으로 "플랜"으로 처리 (단일 레시피 = 레시피 1개짜리 플랜).
사용자에게 보여줄 때만 구분:

| 조건 | 표시 |
|------|------|
| 레시피 1개 | "레시피 실행" 형태 (플랜이라는 말 안 씀) |
| 레시피 2개 이상 | "플랜" 형태 (묶음 표시) |

## 히스토리 표시

```
히스토리:
  08/27 14:30 | 📋 플랜: 입사지원 (3건)     | ✅ 성공 | 12.5s
    └ 이력서 작성 ✅
    └ 포지션 탐색 ✅
    └ 입사지원 ✅
  08/27 14:00 | 📄 회원가입                 | ✅ 성공 | 2.1s
  08/27 13:30 | 📄 공고 생성                | ❌ 실패 | 0.5s
```

- 플랜: 묶음으로 보여줌. 펼치면 개별 레시피 결과 확인 가능.
- 단일 레시피: 독립 건으로 표시.

## AI 플랜 제안 기준

- AI가 매번 추론 (선행 레시피 메타 정의 없음)
- 단일 레시피로 처리 가능하면 → 바로 레시피 실행
- 사전 조건이 필요하다고 판단하면 → 플랜 제안

## 실행 중 취소

- 현재 레시피의 현재 스텝까지 완료 후 중단. 나머지 레시피 미실행.
- 히스토리: "부분 완료" 상태로 저장
- [이어서 실행] 제공 (중단 지점부터 재개)
- 이미 완료된 레시피 결과는 보존

```
📋 플랜 실행 중 — 중단됨

✅ 1. 이력서 작성 — RES-001
⏹️ 2. 포지션 탐색 — 스텝 2/4에서 중단
⬜ 3. 입사지원 — 미실행
```
