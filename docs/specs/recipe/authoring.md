# 레시피 작성 UI/UX

## 작성 위치

- 별도 페이지: 넓은 화면에서 full form 편집
- 사이드 패널: 간단한 수정 시 (추후)
- 동일 컴포넌트를 양쪽에서 재사용

## 화면 구성

세로 스크롤 form 구조:

```
┌─────────────────────────────────────┐
│ 레시피 작성                     [저장] │
├─────────────────────────────────────┤
│ 레시피명: [________________]          │
│ 설명:    [________________]          │
│ 대상 서비스: [user-service ▾]        │
│ 태그:    [___] [___] [+추가]         │
│ 공개범위: (●공통 ○개인)               │
├─────────────────────────────────────┤
│ 사용자 입력 변수                      │
│ ┌─────────────────────────────────┐ │
│ │ productId: 상품 ID (text)  [🗑] │ │
│ │ quantity: 수량 (number)    [🗑] │ │
│ │ [+ 변수 추가]                    │ │
│ └─────────────────────────────────┘ │
├─────────────────────────────────────┤
│ 스텝                                │
│                                     │
│ ① 회원 목록 조회            [≡] [🗑] │
│   타입: API                         │
│   서브도메인: [user-service ▾]       │
│   API: [GET /api/v1/members ▾]      │
│   Extract: memberId = $.data[0].id  │
│                                     │
│ ② 주문 생성                 [≡] [🗑] │
│   타입: API                         │
│   서브도메인: [order-service ▾]      │
│   API: [POST /api/v1/orders ▾]      │
│   Body: { "memberId": "{{...}}" }   │
│   전략: FIXED                       │
│                                     │
│ ③ 결과 가공                 [≡] [🗑] │
│   타입: 스크립트                     │
│   코드: [에디터]                     │
│                                     │
│ [+ 스텝 추가]                        │
└─────────────────────────────────────┘
```

## 인터랙션

- [≡] = 드래그 핸들 (순서 변경)
- 각 스텝 접기/펼치기 가능
- 서브도메인/API는 스펙에서 가져온 목록으로 드롭다운 선택
- 변수 참조 시 자동완성 (이전 스텝 extract + userInput)

## 변수 자동완성

스텝 body 입력란에서 `{{` 타이핑 시:

```
┌───────────────────────────────┐
│ 사용 가능한 변수               │
│ ─────────────────────────────│
│ 📥 사용자 입력                 │
│   userInput.productId         │
│   userInput.quantity          │
│ ─────────────────────────────│
│ 📤 스텝 1: 회원 목록 조회       │
│   memberId ($.data[0].id)     │
│   memberName ($.data[0].name) │
│ ─────────────────────────────│
│ 📄 전체 응답                   │
│   Step0 (원시 JSON)           │
└───────────────────────────────┘
```

- 이전 스텝의 extract 정의에서 자동 목록 생성
- 클릭 시 `{{memberId}}` 형태로 자동 삽입
- 스텝 순서 변경 시 참조 가능한 변수 목록 자동 갱신

## 유효성 검증

- 저장 시: 스펙 호환성 검증 (API가 스펙에 존재하는지)
- 서브레시피: 순환 참조 검증
- 필수 필드 미입력 경고
