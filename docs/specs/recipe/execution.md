# 레시피 실행 플로우

## 실행 진입

```
사용자 발화 (채팅)
    │
    ▼
AI 의도 분석 → 레시피 매칭 (참조 태그 있으면 우선 참조)
    │
    ├─ 매칭됨 → 레시피 간략 설명 + 실행 모드 선택
    │            ├─ [자동 실행] → 기본값 + AI로 진행
    │            └─ [직접 입력하며 실행] → 매 입력 스텝마다 액션 피커
    │
    └─ 매칭 안 됨 → 안내 메시지
```

## 실행 모드

레시피 실행 시 사용자에게 모드를 선택하게 함:

```
AI: "입사지원" 레시피를 찾았어요.
    로그인 → 이력서 확인 → 공고 선택 → 지원 순서로 진행됩니다.

    [자동 실행] [직접 입력하며 실행]
```

| 모드 | 동작 |
|------|------|
| **자동 실행** | 기본값 + AI 판단으로 진행. 판단 불가능한 것만 중간에 물어봄 |
| **직접 입력하며 실행** | 매 사용자 입력 스텝마다 액션 피커로 물어봄 |

사용자가 발화에서 이미 값을 지정한 경우("네이버 백엔드로 입사지원 해줘") 해당 값은 자동 반영.

## 실행 중 진행 상태 표시

진행 상태 블록은 대화 메시지처럼 스크롤되는 형태로 표시 (상단 고정 아님).

```
📋 입사지원 실행 중

✅ 1. 로그인 확인
✅ 2. 이력서 확인 — "프론트엔드 개발자 이력서" 발견
⏭️ 3. 회원가입 (스킵)
🔄 4. 공고 선택 (입력 대기 중)
⬜ 5. 입사지원 제출
⬜ 6. 결과 확인
```

| 아이콘 | 의미 |
|--------|------|
| ✅ | 완료 — 옆에 결과 한 줄 표시 (30자 이내) |
| 🔄 | 실행 중 / 입력 대기 |
| ⬜ | 대기 |
| ⏭️ | 조건 미충족으로 스킵 |
| ❌ | 실패 |

- 사용자 입력 필요 시 해당 스텝에서 액션 피커 노출
- 레시피 연속 실행 시 이전 실행 결과도 스크롤로 확인 가능

## 실행 중 입력 제한

한 대화방에서 동시에 여러 요청을 보낼 수 없음 (대화방 단위 락).

| 상태 | 입력 영역 |
|------|-----------|
| AI 응답 생성 중 | 입력 차단 |
| 레시피 자동 실행 중 (API 호출 등) | 입력 차단 + [중지] 버튼 표시 |
| 레시피 사용자 입력 대기 | 액션 피커만 활성화, 자유 채팅 차단 |
| 유휴 | 정상 사용 |

다른 대화방으로 이동하면 해당 대화방은 독립적으로 사용 가능.

### 중지 버튼

```
┌─────────────────────────────────────────────┐
│  레시피 실행 중...                    [중지]  │
└─────────────────────────────────────────────┘
```

- [중지] 클릭 → 현재 스텝까지 결과 저장, 이후 스텝 취소
- 진행 상태 블록에 중단 표시

### 취소 동작

- 액션 피커에서 [취소] 클릭 → 전체 레시피 중단
- AI "취소되었습니다" 응답

## 실행 완료

- AI가 "레시피 실행이 완료되었습니다" 메시지 출력
- 카드 UI (결과 제공형) 표시: [결과 보기] → 사이드 패널에 결과 노출
- 사이드 패널의 히스토리 목록 refresh
