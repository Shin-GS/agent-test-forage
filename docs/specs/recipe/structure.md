# 레시피 구조

## 소유 구분

- **공통 레시피** — 관리자가 생성, 모든 사용자에게 노출
- **개인 레시피** — 본인만 사용

## 메타 정보

| 항목 | 설명 | 필수 |
|------|------|------|
| 레시피명 | 식별 + AI 매칭용 | ✅ |
| 설명 | AI 의도 매칭에 활용 | ✅ |
| 대상 서비스 | 어느 사이트를 위한 레시피인지 (단일 선택) | ✅ |
| 태그 | 분류/검색/필터용 (복수 입력) | 선택 |
| 공개 범위 | 공통 / 개인 | ✅ |
| 사용자 입력 변수 | 실행 시 사용자에게 물어볼 데이터 | 선택 |
| 스텝 목록 | 실행할 작업 순서 | ✅ |

## 스텝 타입

| 타입 | 역할 |
|------|------|
| **API** | 외부 서버 API 호출 |
| **스크립트** | JavaScript 실행 (데이터 가공, 조건 판단) |
| **레시피** | 다른 레시피를 서브레시피로 호출 |
| **사용자 입력** | 실행 중 사용자에게 데이터 요청 (액션 피커) |

### API 타입

| 항목 | 설명 |
|------|------|
| 스텝명 | 식별용 |
| 대상 서브도메인 | 스펙 목록에서 선택 |
| API | method + path (스펙에서 선택) |
| Body | 요청 본문 (변수 바인딩 가능) |
| Body 생성 전략 | FIXED / AI_GENERATE / AI_FILL |
| AI 힌트 | AI 컨텍스트 (AI 전략 사용 시) |
| Extract | 응답에서 추출할 변수 (JSONPath) |
| 조건 (선택) | 실행 조건. 불만족 시 스킵 |

### 스크립트 타입

| 항목 | 설명 |
|------|------|
| 스텝명 | 식별용 |
| JavaScript 코드 | context 객체로 모든 변수 접근 가능 |
| 조건 (선택) | 실행 조건. 불만족 시 스킵 |

### 레시피 타입 (서브레시피)

| 항목 | 설명 |
|------|------|
| 스텝명 | 식별용 |
| 대상 레시피 | 호출할 레시피 선택 |
| 조건 (선택) | 실행 조건. 불만족 시 스킵 |

- 순환 참조 방지: 레시피 저장 시 서브레시피 호출 순환 검증

### 사용자 입력 타입

| 항목 | 설명 |
|------|------|
| 스텝명 | 식별용 |
| 입력 변수 목록 | 해당 스텝에서 사용자에게 물어볼 필드 정의 |
| 조건 (선택) | 실행 조건. 불만족 시 스킵 |

- 자동 실행 모드: 기본값이 있으면 물어보지 않고 사용
- 직접 입력 모드: 매번 액션 피커로 물어봄

## 조건 분기

각 스텝에 `condition` 필드를 붙여 조건부 실행/스킵 가능. 1차원 순차 구조 유지.

```json
{
  "name": "회원가입",
  "type": "recipe",
  "recipeId": 123,
  "condition": "{{Step0.statusCode}} === 401"
}
```

- 조건 만족 → 스텝 실행
- 조건 불만족 → 스킵하고 다음 스텝으로

## 스텝 간 데이터 전달

| 스코프 | 접근 방식 | 설명 |
|--------|-----------|------|
| 사용자 입력 | `{{userInput.변수명}}` | 액션 피커에서 받은 값 |
| 이전 스텝 추출값 | `{{변수명}}` | extract로 뽑은 값 |
| 이전 스텝 전체 응답 | `{{Step0}}`, `{{Step1}}` | 원시 응답 전체 |

## 스크립트에서의 변수 접근

```javascript
function execute(context) {
  const memberId = context.memberId;       // extract된 값
  const rawResponse = context.Step0;       // 0번 스텝 전체 응답
  const userInput = context.userInput;     // 사용자 입력값
  return { processedData: "..." };         // 다음 스텝에서 참조 가능
}
```
