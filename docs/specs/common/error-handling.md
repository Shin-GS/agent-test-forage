# 에러 처리 정책

## 레시피 실행 중 에러

스텝 실행 중 에러(500, 타임아웃 등) 발생 시:

- 진행 상태에서 해당 스텝을 ❌ 표시
- AI가 "스텝 N에서 실패했습니다" 메시지 출력
- 카드 UI로 [다시 실행] 버튼 표시 (실패한 스텝부터 재개)

## 인증/권한 에러 (401/403)

레시피 실행 중 인증/권한 에러 감지 시, 상태코드에 따라 다르게 처리:

### 401 — 미인증 (로그인 필요)

1. 카드 UI 표시: [로그인하러 가기] + [로그인 완료]
2. [로그인하러 가기] → 새 탭으로 해당 서브도메인의 loginPageUrl
3. [로그인 완료] 클릭 → 중단된 스텝부터 재개
4. 여전히 401 → "로그인이 처리되지 않은 것 같습니다. 다시 로그인 부탁드립니다." + 같은 카드 재노출

### 403 — 권한 부족 (로그인은 됐으나 접근 권한 없음)

1. 해당 스텝 ❌ 표시
2. AI가 "이 API를 실행할 권한이 없습니다. 해당 서비스에서 권한을 확인해주세요." 메시지 출력
3. 카드 UI: [다른 계정으로 로그인] + [레시피 중단]
4. [다른 계정으로 로그인] → 새 탭으로 loginPageUrl (권한 있는 계정으로 전환)
5. 로그인 완료 후 → 해당 스텝부터 재개
