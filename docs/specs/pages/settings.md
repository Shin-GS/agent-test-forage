# 설정 페이지

## URL

`/settings`

## 성격

**대부분 읽기 전용(조회) 페이지다.** AI 설정과 레시피 실행 설정은 운영 안정성/비용 통제를 위해
사용자·관리자 모두 화면에서 바꿀 수 없고, **서버 설정 파일(.env / application.yml)로만** 변경한다.
화면에서는 현재 적용값을 확인만 한다. 편집 가능한 항목은 계정(비밀번호 변경)뿐이다.

> 근거: AI 모델/타임아웃 같은 값은 비용·안정성에 직결되므로 런타임 변경 경로를 두지 않는다.
> 설정 소스를 파일 하나로 고정하면 "누가 언제 바꿨나"를 추적할 필요가 없고, 잘못된 값으로 인한
> 장애 가능성도 없앤다(설정 변경 = 배포/재기동 경로로 통제).

## 섹션별 항목

### AI 설정 (읽기 전용)

현재 서버에 적용된 AI 설정을 표시만 한다. 편집 컨트롤(드롭다운/입력/저장) 없음.

| 항목 | 설명 |
|------|------|
| AI Provider | **OpenRouter 고정** (OpenAI 호환 API). 표시만 |
| Reasoning 모델 | 의도 분석/플랜/조회 판단용 모델 (예: `openai/gpt-4o`). 표시만 |
| Fast 모델 | 필드 생성/요약용 모델 (예: `openai/gpt-4o-mini`). 표시만 |
| 대화 이력 전달 수 | AI에게 전달하는 최근 대화 건수 (기본 15). 표시만 |
| 호출 타임아웃 | AI 호출 타임아웃 초 (기본 30). 표시만 |

- **Provider는 OpenRouter로 고정**한다. OpenRouter가 OpenAI 호환 API로 여러 모델(ChatGPT 계열 등)을
  단일 엔드포인트로 제공하므로, 모델 선택은 "OpenRouter 모델명"으로 표현된다(예: `openai/gpt-4o`).
- 값 변경은 서버 설정 파일(`AI_BASE_URL`/`AI_API_KEY`/`AI_MODEL_REASONING`/`AI_MODEL_FAST` 등)로만 한다.
- 조회 API로 현재값을 내려 화면에 표시한다(시크릿인 API 키는 표시하지 않는다).

### 레시피 실행 설정 (읽기 전용)

| 항목 | 설명 |
|------|------|
| 스텝 타임아웃 | 개별 스텝 타임아웃 (기본 30초). 표시만 |
| 전체 타임아웃 | 레시피 전체 타임아웃 (기본 300초). 표시만 |

- 값 변경은 서버 설정 파일로만 한다.

### 계정 (편집 가능)

| 항목 | 설명 |
|------|------|
| 비밀번호 변경 | 현재 비밀번호 확인 + 새 비밀번호 입력 (유일한 편집 항목) |

## 조회 API

- `GET /api/v1/settings` — 현재 적용된 AI/실행 설정을 읽기 전용으로 반환 (API 키 등 시크릿 제외)
- 저장/수정 API는 두지 않는다(설정 변경은 파일 경로로만).
