# 설정 페이지

## URL

`/settings`

## 화면 구성

```
┌──────────────────────────────────────────────────────────┐
│ 설정                                                     │
├──────────────────────────────────────────────────────────┤
│ 📌 AI 설정                                              │
│   AI Provider: [OpenAI ▾]                                │
│   모델: [gpt-4o ▾]                                       │
│   대화 이력 전달 수: [15] 건                              │
│                                                          │
│ 📌 레시피 실행 설정                                       │
│   스텝 타임아웃: [30] 초                                  │
│   전체 타임아웃: [300] 초                                 │
│                                                          │
│ 📌 계정                                                  │
│   비밀번호 변경                                           │
│                                                          │
│                                     [저장]               │
└──────────────────────────────────────────────────────────┘
```

## 섹션별 항목

### AI 설정

| 항목 | 설명 |
|------|------|
| AI Provider | OpenAI / Claude / OpenRouter |
| 모델 | provider별 사용 가능 모델 목록 |
| 대화 이력 전달 수 | AI에게 전달하는 최근 대화 건수 (기본 15) |

### 레시피 실행 설정

| 항목 | 설명 |
|------|------|
| 스텝 타임아웃 | 개별 스텝 타임아웃 (기본 30초) |
| 전체 타임아웃 | 레시피 전체 타임아웃 (기본 300초) |

### 계정

| 항목 | 설명 |
|------|------|
| 비밀번호 변경 | 현재 비밀번호 확인 + 새 비밀번호 입력 |
