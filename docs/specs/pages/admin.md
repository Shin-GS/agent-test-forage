# 관리자 페이지

## 개요

관리자 계정으로 로그인 시 추가로 접근 가능한 페이지.
관리자도 일반 사용자 기능(채팅, 레시피 실행)을 동시에 사용하므로, 별도 어드민 사이트가 아닌 기존 네비게이션의 연장선으로 제공.

## 네비게이션

사이드바 하단에 관리자 전용 아이콘 추가 (일반 사용자에게는 안 보임):

```
┌─────────┐
│ 대화 목록 │
│ ...     │
├─────────┤
│ 📋 📊 ⚙️ │  ← 공통 (레시피 관리, 히스토리, 설정)
│ ──────  │
│ 🖥️ 👥   │  ← 관리자 전용 (스펙 관리, 사용자 관리)
└─────────┘
```

## 스펙 관리 (`/admin/specs`)

### 목록

```
┌──────────────────────────────────────────────────────────┐
│ 스펙 관리                                                │
├──────────────────────────────────────────────────────────┤
│ 서비스명   | baseUrl                  | 상태 | API 수 | 마지막 heartbeat │
│ ──────────────────────────────────────────────────────────────────────── │
│ demo-shop  | https://shop.example.com | 🟢 ACTIVE | 42개 | 10초 전       │
│ demo-pay   | https://pay.example.com  | 🟡 STALE  | 35개 | 6분 전        │
│ demo-auth  | https://auth.example.com | 🟢 ACTIVE | 28개 | 5초 전        │
└──────────────────────────────────────────────────────────┘
```

### 상세 (행 클릭)

- 서비스 설명 (description/domain/capabilities/notes) — 표시 + [편집] (관리자 수정, yml보다 우선)
- API 엔드포인트 목록 (method + path + 제어 상태 + DEPRECATED 여부)
- 인증 프로필 정보 (name + loginPageUrl)
- [비활성화] / [활성화] 토글
- [삭제] 버튼 (확인 팝업, 소프트 삭제)

### 스펙 수동 관리 (비활성/삭제)

서버 URL 변경 등으로 좀비 스펙(구 baseUrl)이 남을 수 있어, 관리자가 직접 정리한다.

| 액션 | 동작 |
|------|------|
| 비활성화 | STATUS = INACTIVE. AI 매칭/실행 대상에서 제외. 자동 삭제 대상 아님 |
| 활성화 | INACTIVE → ACTIVE 복귀 (관리자만) |
| 삭제 | 소프트 삭제. 참조 레시피는 유효성 검증에서 경고 |

- 예: `shop-api.acme.com` → `shop.acme.com`으로 URL 변경 시, 구 URL 스펙은 heartbeat 끊겨 STALE → 관리자가 비활성/삭제로 정리
- INACTIVE/삭제된 스펙을 참조하는 레시피는 실행 전 유효성 검증에서 경고

## 사용자 관리 (`/admin/users`)

### 목록

```
┌──────────────────────────────────────────────────────────┐
│ 사용자 관리                                    [+ 초대]   │
├──────────────────────────────────────────────────────────┤
│ 아이디 | 역할 | 가입일 | 마지막 접속 | 상태               │
│ ──────────────────────────────────────────────────────── │
│ admin   | 관리자 | 2026-08-01 | 10분 전 | 활성            │
│ user1   | 사용자 | 2026-08-15 | 1시간 전 | 활성           │
│ user2   | 사용자 | 2026-08-20 | 3일 전 | 비활성           │
└──────────────────────────────────────────────────────────┘
```

### 기능

| 기능 | 설명 |
|------|------|
| 역할 변경 | 사용자 ↔ 관리자 |
| 계정 비활성화/활성화 | 로그인 차단/허용 |
| 비밀번호 초기화 | 임시 비밀번호 발급 |
| 사용자 초대 | 아이디 + 역할 지정 → 임시 비밀번호 생성 |

## 공통 레시피 관리

별도 관리 페이지 불필요. 기존 레시피 편집 페이지(`/recipes`)에서:
- 관리자만 "공개 범위: 공통" 선택 가능
- 일반 사용자는 "개인"만 선택 가능
