# 관리자 페이지

## 개요

관리자 계정으로 로그인 시 추가로 접근 가능한 페이지.
관리자도 일반 사용자 기능(채팅, 레시피 실행)을 동시에 사용하므로, 별도 어드민 사이트가 아닌 기존 네비게이션의 연장선으로 제공.

## 네비게이션

사이드바 하단에 관리자 전용 아이콘 추가 (일반 사용자에게는 안 보임):

```
┌─────────┐
│ 대화 목록 │
│ ...     │
├─────────┤
│ 📋 📊 ⚙️ │  ← 공통 (레시피 관리, 히스토리, 설정)
│ ──────  │
│ 🖥️ 👥   │  ← 관리자 전용 (스펙 관리, 사용자 관리)
└─────────┘
```

## 스펙 관리 (`/admin/specs`)

### 목록

```
┌──────────────────────────────────────────────────────────┐
│ 스펙 관리                                                │
├──────────────────────────────────────────────────────────┤
│ 서비스명 | 환경 | 상태 | API 수 | 마지막 heartbeat       │
│ ──────────────────────────────────────────────────────── │
│ 사람인   | default | 🟢 ACTIVE | 42개 | 10초 전          │
│ 잡코리아 | default | 🟡 STALE  | 35개 | 6분 전           │
│ 쇼핑몰   | staging | 🟢 ACTIVE | 28개 | 5초 전           │
└──────────────────────────────────────────────────────────┘
```

### 상세 (행 클릭)

- API 엔드포인트 목록 (method + path + 제어 상태)
- 인증 프로필 정보 (name + loginPageUrl)
- [삭제] 버튼 (확인 팝업)

## 사용자 관리 (`/admin/users`)

### 목록

```
┌──────────────────────────────────────────────────────────┐
│ 사용자 관리                                    [+ 초대]   │
├──────────────────────────────────────────────────────────┤
│ 아이디 | 역할 | 가입일 | 마지막 접속 | 상태               │
│ ──────────────────────────────────────────────────────── │
│ admin   | 관리자 | 2026-08-01 | 10분 전 | 활성            │
│ user1   | 사용자 | 2026-08-15 | 1시간 전 | 활성           │
│ user2   | 사용자 | 2026-08-20 | 3일 전 | 비활성           │
└──────────────────────────────────────────────────────────┘
```

### 기능

| 기능 | 설명 |
|------|------|
| 역할 변경 | 사용자 ↔ 관리자 |
| 계정 비활성화/활성화 | 로그인 차단/허용 |
| 비밀번호 초기화 | 임시 비밀번호 발급 |
| 사용자 초대 | 아이디 + 임시 비밀번호 생성 |

## 공통 레시피 관리

별도 관리 페이지 불필요. 기존 레시피 편집 페이지(`/recipes`)에서:
- 관리자만 "공개 범위: 공통" 선택 가능
- 일반 사용자는 "개인"만 선택 가능
