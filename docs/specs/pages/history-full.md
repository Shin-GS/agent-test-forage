# 전체 히스토리 페이지

## URL

`/history`

## 화면 구성

```
┌──────────────────────────────────────────────────────────┐
│ 실행 히스토리                    [검색] [필터: 서비스 ▾]   │
├──────────────────────────────────────────────────────────┤
│ 날짜 | 레시피명 | 서비스 | 상태 | 소요시간               │
│ ──────────────────────────────────────────────────────── │
│ 08/27 14:30 | 입사지원 | 사람인 | ✅ 성공 | 3.2s         │
│ 08/27 14:25 | 회원가입 | 사람인 | ✅ 성공 | 1.8s         │
│ 08/27 10:00 | 재고확인 | 쇼핑몰 | ❌ 실패 | 0.5s         │
│ ...                                                      │
├──────────────────────────────────────────────────────────┤
│ 페이지네이션                                             │
└──────────────────────────────────────────────────────────┘
```

## 기능

| 기능 | 설명 |
|------|------|
| 검색 | 레시피명 |
| 필터 | 서비스, 상태 (성공/실패), 날짜 범위 |
| 정렬 | 최신순 (기본) |
| 상세 보기 | 행 클릭 → 실행 결과 상세 (스텝별 결과 + 원본 JSON) |
| 페이지네이션 | 페이지 단위 또는 무한 스크롤 |

## 실행 결과 상세

행 클릭 시 모달 또는 별도 뷰로 상세 표시:
- 레시피명, 실행 시각, 실행 모드
- 스텝별 결과 (상태 + 요약 한 줄)
- 각 스텝 접기/펼치기로 원본 응답 JSON 확인
- 사용자 입력값
