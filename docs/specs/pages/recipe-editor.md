# 레시피 편집 페이지

## URL

- `/recipes` — 레시피 목록 (관리용)
- `/recipes/new` — 생성
- `/recipes/{id}/edit` — 수정

## 레시피 목록 페이지

패널의 레시피 목록은 "실행할 레시피 찾기"용. 이 페이지는 "관리하기 위한 뷰".

목록 API는 **"공통 전체 + 요청자 본인의 개인 레시피"**만 반환한다(남의 개인 레시피 미노출, [auth.md 레시피 권한 매트릭스](../common/auth.md#레시피-권한-매트릭스)).

| 기능 | 설명 |
|------|------|
| 전체 레시피 조회 | 검색 + 다중 선택 필터 (서비스, 범위, 태그) + 정렬 |
| 생성 | [+ 레시피 만들기] → `/recipes/new` |
| 편집 | 행 클릭 → `/recipes/{id}/edit` |
| 삭제 | ConfirmModal (권한 있는 항목만) |
| 복제 | 기존 레시피 복사. 공통 레시피 복제 시 개인 사본으로 생성([authoring.md 복제](../recipe/authoring.md#복제-공통--개인-사본)) |

### 검색 / 필터 / 정렬

**검색**
- 이름/설명 대상 텍스트 검색. 입력은 **디바운스**(과도 요청 방지) 후 질의.

**다중 선택 필터** — 서비스 / 범위 / 태그 각각 복수 선택 가능.
- **빈 선택 = 전체**(해당 축으로 거르지 않음).
- **서비스 필터는 메타 대상 서비스 기준**으로 거른다(스텝이 내부적으로 호출하는 서비스로는 필터하지 않음, [structure.md 서비스의 두 층위](../recipe/structure.md#서비스의-두-층위-실행-vs-분류)).
- 선택한 조건은 **필터 칩**으로 노출하고, 칩의 개별 `✕`로 하나씩 해제.
- [필터 초기화] 버튼으로 전 축 일괄 해제.
- 활성 필터 요약 문구 노출(예: "서비스 2 · 범위 1 · 태그 3").
- 태그는 각 행의 태그 칩을 클릭하면 해당 태그가 필터에 추가된다.

**정렬** — 기준 + 방향 토글(오름/내림).

| 기준 | 동작 |
|------|------|
| 최근 사용순 (기본) | `lastUsedAt DESC`, null은 뒤로 |
| 사용 많은순 | `usageCount DESC` |
| 이름순 | 이름 기준 |
| 최근 수정순 | 수정 시각 기준 |

**URL 쿼리 동기화**: 검색어/필터/정렬 상태를 URL 쿼리에 반영한다. 새로고침·링크 공유 시 동일한 목록 상태가 복원된다.

### 목록 행 표기

각 행에 아래 정보를 표시한다.

- **범위 배지**: 🌐 공통(COMMON) / 🔒 개인(PRIVATE)
- **이름** + 그 아래 **설명 1줄**(넘치면 말줄임)
- **유효성 경고**: `validationStatus`가 INVALID면 ⚠️ 경고 아이콘 + 사유 툴팁
- **결과 카운트**: 현재 필터/검색에 매칭된 레시피 개수 노출
- **hover 액션**: 행에 마우스 오버 시 액션(편집/복제/삭제) 노출. **권한별로 게이팅**(아래 참조)

### 권한별 액션 게이팅

응답의 `canEdit`(요청자 기준 편집 가능 여부, [auth.md 권한 힌트](../common/auth.md#레시피-권한-매트릭스))로 액션 노출을 제어한다.

| 대상 | 편집 | 삭제 | 복제 |
|------|------|------|------|
| 내 개인 레시피 | ✅ | ✅ | ✅ |
| 공통 레시피 (ADMIN) | ✅ | ✅ | ✅ |
| 공통 레시피 (일반 사용자) | 🔒 읽기 전용 진입 | ❌ | ✅ (개인 사본) |

- `canEdit`은 UX 힌트이며 실제 권한은 서버가 강제한다. 게이팅으로 숨겨도 서버는 권한 없는 변경 요청을 거부한다(공통 변경 시도 403, 남의 개인 접근 404 — [404 vs 403 원칙](../common/auth.md#404존재-은폐-vs-403권한-부족-원칙)).

### 삭제 확인

- 삭제는 **ConfirmModal**로 확인한다. `window.confirm` 사용 금지(디자인 시스템 [ConfirmModal](../../design/shared/system.html) 사용).

## 편집 페이지

사이드 패널 + 채팅 없이 전체 화면 사용.

```
┌──────────────────────────────────────────────────────────┐
│ ← 목록으로     레시피 편집        [버전 기록] [저장] [삭제] │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  (authoring.md에 정의된 form 구조 — 넓은 화면 버전)        │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

상세 form 구조는 [레시피 작성 UI/UX](../recipe/authoring.md) 참조.

### 읽기 전용 모드 (공통 레시피 + 일반 사용자)

일반 사용자가 공통 레시피를 열면 **읽기 전용 편집 화면**으로 진입한다.

- 모든 입력 필드 비활성(disabled), [저장]/[삭제]/[복원] 버튼 숨김 또는 비활성.
- **[버전 기록] 진입 버튼은 노출**한다. 읽기 전용에서도 버전 기록 drawer 열람 + 특정 버전 미리보기는 가능하며, 미리보기의 [복원] 버튼만 숨긴다(아래 [버전 기록](#버전-기록) 참조).
- 상단에 "공통 레시피 · 읽기 전용" 안내 + [개인 사본으로 복제] 버튼 노출(복제 후 자기 사본을 편집).
- 진입 판정은 응답 `canEdit=false`로 한다.
- 남의 개인 레시피 URL 직접 접근은 404로 처리(읽기 전용도 아님, 존재 은폐).

## 버전 기록

[버전 기록] 버튼으로 우측 **drawer**를 연다. API는 [레시피 버전 관리](../recipe/versioning.md) 참조.

```
┌───────────────────────────┬──────────────┐
│ 레시피 편집                 │ 버전 기록  ✕ │
│                           │ ──────────── │
│                           │ v5  방금 전   │  ← 현재
│                           │ v4  1시간 전  │
│                           │ v3  어제      │
│                           │ ...          │
│                           │ [더 보기]     │  ← 커서 페이징
└───────────────────────────┴──────────────┘
```

- 목록은 `GET .../versions`로 커서 페이징(스크롤/[더 보기]로 다음 페이지 로드). 항목 표기: `versionNo` + `createdAt`.
- 항목 클릭 → **미리보기**: `GET .../versions/{versionNo}`로 해당 버전 상세를 불러와, 현재 상세 렌더링 컴포넌트로 읽기 전용 표시(현재 편집 내용은 건드리지 않음).
- 미리보기에서 [이 버전으로 복원] → **복원 확인 ConfirmModal**.
  - 안내 문구: "현재 상태는 버전으로 보관되고, 선택한 버전 내용으로 되돌립니다. 되돌리기도 이력에 남습니다."
  - 확인 시 `POST .../versions/{versionNo}/restore` 호출 → 성공 시 편집 화면을 복원된 최신 상태로 갱신 + drawer 목록 새로고침.
  - 복원 결과 `validationStatus=INVALID`면 편집 화면 상단에 ⚠️ 경고 배너(사유 표시). 복원 자체는 성공 취급([복원 정책](../recipe/versioning.md#복원-정책)).
- **권한**: [버전 기록] 진입과 목록 열람·특정 버전 미리보기는 **읽기 전용 모드(공통을 non-admin이 열 때)에서도 가능**하다. **복원 버튼만** 편집 권한이 있을 때 노출한다(개인=소유자, 공통=ADMIN). 즉 읽기 전용에서는 열람·미리보기까지 되고 복원 버튼은 숨긴다. 노출 판정은 응답 `canEdit`을 따른다([versioning.md 특정 버전 조회 응답의 canEdit](../recipe/versioning.md#get-apiv1recipesidversionsversionno--특정-버전-내용)).

## 동작

- 저장 시 유효성 검증 (스펙 호환성, 순환 참조, 필수 필드)
- 삭제 확인 ConfirmModal
- 수정 시 버전 자동 생성 (versioning.md 참조)

## 백로그 (구현 안 함, 기록만)

- 즐겨찾기(레시피 핀 고정)
- 목록 일괄 작업(다중 선택 후 일괄 삭제/이동)
- 빠른 필터 프리셋(자주 쓰는 필터 조합 저장)
