# 사이드 패널 케이스

## 참조 기획

- [패널 구조](../../specs/panel/overview.md)
- [작업 히스토리](../../specs/panel/history.md)

## 개요

채팅 우측에 항상 열려있는 보조 패널. 레시피 탐색 + 히스토리 확인 + 결과 상세.
스택 네비게이션 (상세 → 뒤로가기 → 목록).

## 케이스 목록

| # | 케이스 | 설명 |
|---|--------|------|
| 1 | 레시피 목록 (기본) | 탭 필터 + 레시피 카드 목록 + 최근 실행 |
| 2 | 레시피 상세 | 스텝 구성 보기 + 실행 버튼 |
| 3 | 히스토리 목록 | 최근 실행 기록 목록 |
| 4 | 실행 결과 상세 | 스텝별 결과 + 입출력 데이터 |
| 5 | 빈 상태 | 레시피 없음 / 히스토리 없음 |

## 케이스 상세

### Case 1: 레시피 목록 (기본)

- 상단: 탭 [레시피] [히스토리]
- 검색 입력 필드
- 필터 탭: [전체] [즐겨찾기] [내 레시피] [공통]
- 레시피 항목:
  - 레시피명 + 서비스 뱃지 + ⭐ 즐겨찾기
  - 마지막 실행 한 줄 (시각 + 상태)
  - [▶] 바로 실행 버튼
- 하단: [+ 레시피 만들기] 버튼

### Case 2: 레시피 상세

- 상단: [← 뒤로] + 레시피명
- 레시피 정보: 서비스, 작성자, 설명
- 스텝 목록 (순서대로):
  - 스텝 번호 + 이름 + 타입 뱃지 (API/스크립트/사용자입력)
- 하단 고정: [실행하기] 버튼

### Case 3: 히스토리 목록

- 상단: 탭 [레시피] [히스토리] — 히스토리 활성
- 실행 기록 목록:
  - 레시피명 + 실행 시각
  - 상태 뱃지 (성공/부분실패/실패)
  - 간략 요약 (N/M 스텝 성공)
- 항목 클릭 → 실행 결과 상세

### Case 4: 실행 결과 상세

- 상단: [← 뒤로] + "실행 결과"
- 기본 정보: 레시피명, 실행 시각, 소요 시간
- 스텝별 결과 목록:
  - 스텝명 + 상태 (✓/✕)
  - 펼치면 입출력 JSON (코드 블록)
- 실패 스텝: 에러 메시지 표시

### Case 5: 빈 상태

- 레시피 없음: "아직 레시피가 없어요" + [레시피 만들기]
- 히스토리 없음: "아직 실행한 레시피가 없어요"
- 검색 결과 없음: "'{검색어}'에 해당하는 레시피가 없어요"

## 접근성

- 스택 네비게이션: 뒤로가기 버튼에 aria-label
- 레시피 목록: role="list" + role="listitem"
- 실행 버튼: aria-disabled when 대화방 처리 중
