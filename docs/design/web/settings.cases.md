# 설정 페이지 케이스

## 참조 기획

- [설정 페이지](../../specs/pages/settings.md)

## 레이아웃

별도 페이지. 전체 화면, 중앙 정렬. AI/실행 설정은 **읽기 전용 표시**, 편집 항목은 비밀번호뿐.

## 케이스 목록

| # | 케이스 | 설명 |
|---|--------|------|
| 1 | 기본 (읽기 전용) | AI 설정 + 실행 설정을 값 텍스트로 표시(편집 컨트롤/저장 버튼 없음) + 계정 섹션 |
| 2 | 비밀번호 변경 | 비밀번호 변경 폼 펼침 |
| 3 | 비밀번호 변경 완료 | 비밀번호 변경 성공 토스트 |

## 접근성

- 각 섹션 heading으로 구분
- AI/실행 설정은 편집 불가임을 안내 문구(ⓘ)로 명시
- 비밀번호 변경 form 필드에 label 연결
- 비밀번호 변경 성공 시 aria-live 알림
