# 로그인 화면 케이스

## 참조 기획

- [로그인, 권한/역할](../../specs/common/auth.md)

## 케이스 목록

| # | 케이스 | 설명 |
|---|--------|------|
| 1 | 기본 상태 | 아이디/비밀번호 입력 폼. 로그인 버튼 비활성 (입력 전) |
| 2 | 입력 중 | 아이디/비밀번호 입력된 상태. 로그인 버튼 활성 |

| 4 | 로그인 실패 | 에러 메시지 표시 ("아이디 또는 비밀번호가 올바르지 않습니다") |

## 케이스 상세

### Case 1: 기본 상태

- 화면 중앙에 로그인 카드 배치
- 앱 로고 + 제목 ("AI Test Forge")
- 아이디 입력 필드 (placeholder: "아이디를 입력하세요")
- 비밀번호 입력 필드 (placeholder: "비밀번호를 입력하세요")
- 로그인 버튼 (비활성, disabled 상태)

### Case 2: 입력 중

- 아이디, 비밀번호 모두 입력된 상태
- 로그인 버튼 활성 (primary 스타일)
- 비밀번호 표시/숨김 토글 아이콘

### Case 3: 로딩

- 로그인 버튼에 스피너 + "로그인 중..." 텍스트
- 입력 필드 disabled
- 버튼 disabled

### Case 4: 로그인 실패

- 에러 alert 표시 (폼 상단)
- 비밀번호 필드 초기화
- 입력 필드와 버튼은 다시 활성
- 에러 메시지: "아이디 또는 비밀번호가 올바르지 않습니다"

## 반응형

- Desktop: 카드 최대 너비 400px, 화면 중앙
- Tablet: 동일 (카드 기반이라 별도 처리 불필요)

## 접근성

- 폼 필드에 적절한 label 연결
- 에러 시 aria-live로 에러 메시지 알림
- Tab 순서: 아이디 → 비밀번호 → 로그인 버튼
