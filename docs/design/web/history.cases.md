# 전체 히스토리 페이지 케이스

## 참조 기획

- [전체 히스토리 페이지](../../specs/pages/history-full.md)

## URL

`/history` — 별도 전체 화면 페이지. 채팅 레이아웃을 벗어난 테이블 뷰.

## 레이아웃

별도 페이지. 전체 화면 테이블 뷰. Tablet 이하(<1024px)에서는 카드 폴백.

## 케이스 목록

| # | 케이스 | 설명 |
|---|--------|------|
| 1 | 목록 (기본) | 실행 히스토리 테이블 + 필터 바 + 결과 카운트("총 N건") |
| 2 | 상세 보기 | 행 클릭 → 모달(ExecutionDetailView). 실행 메타 + 스텝별 결과(펼침 시 원본 JSON) |
| 3 | 빈 상태 | 실행 이력 없음(🕘 + 채팅 유도) |
| 4 | 필터 결과 없음 | 조건에 맞는 이력 없음 + [필터 초기화] |
| 5 | 반응형 카드 폴백 | Tablet 이하(<1024px) — 행을 세로 카드로 전환 |
| 6 | 플랜 히스토리 (백로그) | 플랜 실행 구현 후. 현재는 백로그 안내만 |

## 확정 UX

### 목록 컬럼 (최신순 고정, `startedAt DESC`)

`실행 시각 | 레시피명(+결과 요약 1줄) | 서비스 | 상태 | 소요시간`

- **결과 카운트**: 필터 바 하단에 "총 N건" 표기.
- **행 색 강조는 토큰 기반, 배지-행 색 언어 일치**(하드코딩 금지):
  - 실패(❌)=error 계열(`--color-error-subtle`)
  - 중지(⏹️)=배지가 neutral이므로 행도 **중립 배경**(`--color-bg-hover`) — warning으로 쓰지 않음(배지-행 색 언어 일치).
- **커서 무한 스크롤**: 목록은 `startedAt DESC` 커서 기반 무한 스크롤이 데이터 계약. 테이블/카드 하단 sentinel 도달 시 다음 커서를 요청하고, 로딩 중에는 하단에 로딩 표시(스피너 컴포넌트 재사용), 마지막 페이지 도달 시 종료 문구로 전환.

### 필터 바 (레시피 목록의 FilterDropdown 패턴과 일관)

모든 필터는 **다중 선택 + "빈 선택 = 전체"**. 필터 변경 시 커서 리셋 후 처음부터 재조회.

| 항목 | 방식 |
|------|------|
| 검색 | 레시피명 텍스트(디바운스) |
| 서비스 | 다중 선택 드롭다운(`apiSpecId`) |
| 상태 | 다중 선택 드롭다운 — ✅성공(SUCCESS) / ❌실패(FAILED) / ⏹️중지(STOPPED) / ⏸️취소(CANCELLED) |
| 기간 | 날짜 범위(from~to) — date input 2개 |

- 활성 필터 요약 줄 + 필터 칩(제거 가능) + [필터 초기화].
- 진행중(RUNNING)·부분성공(PARTIAL)은 상태 필터 옵션에서 제외(완료 이력 조회용).

### 상태 아이콘

✅ 성공 / ❌ 실패 / ⏹️ 중지 / ⏸️ 취소 (PARTIAL 행은 목록엔 노출되나 필터 옵션엔 없음)

### 상세 모달 (ExecutionDetailView 재사용)

- 헤더: 레시피명 · 실행 시각 · 실행 모드(자동/직접) · 소요시간 · 상태
- 스텝별: 상태 아이콘 + 요약 1줄, 펼침 시 원본 응답 JSON(`RESPONSE_JSON`) + 사용자 입력값
- 데이터: `GET /api/v1/executions/{id}` — 본인 소유 검증, 타인 접근 404
- 실행 시점 스냅샷 기준 렌더링

## 접근성

- 테이블에 적절한 `thead`/`tbody`, `scope="col"` 헤더
- 상세 모달: `role="dialog"` + `aria-modal="true"` + `aria-labelledby`.
  - 닫기: 헤더 ✕ / 하단 [닫기] 버튼 핸들러 + ESC + 바깥(backdrop) 클릭 닫기 (명세 HTML에 연결됨).
  - **포커스 트랩/복귀는 FE(React) 구현 범위**: 열릴 때 첫 요소(✕) 포커스, 닫으면 트리거(목록 행) 복귀. (명세 HTML은 정적이라 닫기 동작만 연결)
- 필터 변경 시 결과 개수를 `aria-live="polite"`로 알림
- 무한 스크롤 하단 로딩 표시는 `role="status"` + `aria-live="polite"`
- 날짜 input은 `<label for>`로 연결
- 필터 드롭다운: `aria-haspopup`/`aria-expanded` 동기화, ESC/바깥 클릭 닫기, 첫 체크박스 포커스, 닫으면 트리거 복귀
- **반응형 카드 폴백(`exec-cards`)**: 데스크톱 테이블과 동일 데이터의 반응형 대체 표현이라 기본 `aria-hidden="true"`. 단, <1024px 미디어쿼리로 카드가 노출될 때는 `aria-hidden="false"`로 토글해야 스크린리더에서 낭독됨(FE 구현 범위).

## 백로그 (구현 안 함, 기록만)

- [다시 실행] 버튼, 날짜 그룹 헤더, CSV/JSON 내보내기, 통계 요약 바, 멀티 타임존 대응
