## 케이스 목록

| # | 케이스 | 설명 |
|---|--------|------|
| 1 | 목록 (기본) | 실행 히스토리 테이블 + 필터 |
| 2 | 상세 보기 | 행 클릭 → 스텝별 결과 + JSON 펼침 |
